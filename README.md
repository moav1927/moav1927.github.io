# Cuadra · PDF a Excel

Tus documentos, pasados en limpio a Excel: https://moav1927.github.io/pdf-a-excel/

- Todo se procesa en el navegador; ningún archivo se envía a un servidor
  (la política de seguridad de contenido de las páginas bloquea cualquier envío externo).
- `/pdf-a-excel/`: documentos en general. `/contadores/`: facturas electrónicas DIAN.
